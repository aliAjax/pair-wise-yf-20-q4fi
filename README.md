# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 点火通道占用闸

- 预置 8 条点火通道，节点登记节目段落、烟花型号、通道号、点火时刻（mm:ss.mmm）与持续毫秒。
- 保存时把待发批次与已排编排按通道合并、逐发比对：
  - 前一发未熄（燃烧区间重叠）→ 拒绝；
  - 前一发熄灭后冷启动间隔不足 1.5 秒 → 拒绝。
- 任一节点冲突即整批拒绝，已排编排与本地存储都不变；冲突节点可改派空闲通道重提，改派只改通道号，点火时刻与段落保持不变。
- 时间轴按通道分泳道展示已排节点；型号清单按型号 × 通道统计发数。
- 数据仅保存在浏览器 localStorage，不发请求。

### 业务文件拆分

| 文件 | 职责 |
| --- | --- |
| `src/lib/scheduler.ts` | 判定：通道占用比对、冷启动间隔、空闲通道建议、时间码解析 |
| `src/lib/storage.ts` | 存储：localStorage 读写、示例编排、数据校验 |
| `src/App.tsx` | 页面：节点登记、待发批次、冲突提示、泳道时间轴与型号清单 |
